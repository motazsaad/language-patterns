# Between the Lines

A static, four-language field guide to the different ways English, French,
Italian, and Arabic express everyday ideas.

## Explore

The guide includes:

- Everyday expressions and sentence patterns, with searchable translations.
- Comparisons of definite articles, noun gender, and adjective agreement.
- Examples of reflexive verbs, negation, and conjugation.
- An introduction to Arabic root-and-pattern word formation, including place
  nouns, with Arabic examples accompanied by transliteration and English
  meanings.
- A comparison of the letter C in English, French, and Italian, alongside
  notes on Arabic letter names and pronunciation differences.

## Run locally

Open `index.html` in a browser, or serve this directory with any static-file
server. No build step or dependencies are required.

## Publish

The site is deployed to GitHub Pages from the `main` branch using the workflow
in `.github/workflows/pages.yml`.
